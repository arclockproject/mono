# Welcome to ArcLock Project

ArcLock Project is a set of React components and small TypeScript libraries,
published as separate npm packages. Each package can be used on its own.

## Packages {#packages}

| Package | What it is | Docs |
|---|---|---|
| [`@arclockproject/common`](./common/index.mdx) | Reusable React components and small libraries. | [Guides](./common/index.mdx) · [API](/docs/api/common) |
| [`@arclockproject/mmd-player`](./mmd-player/index.mdx) | An MMD (MikuMikuDance) loader and player. | [Guides](./mmd-player/index.mdx) · [API](/docs/api/mmd-player/component) |

## Getting started {#getting-started}

Open a package's page to see how to install it. Each guide page lists anything
else it needs.

## How are these docs organised? {#how-are-these-docs-organised}

- **Guides** (under each package in the sidebar) explain what something is for
  and have **live examples**. Click **Show code** on an example to see and edit
  its code, and the result updates as you type.
- **API** pages list every prop, function, method and type. They are generated
  from the code, so they are always up to date.
- **[Roadmap](./3-roadmap.mdx)** lists what is planned next.
