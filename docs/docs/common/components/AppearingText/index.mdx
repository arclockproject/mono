:::warning[Deprecated]

`AppearingText` is now part of [`Text`](/docs/common/components/Text#typing). Use
`<Text speed={100}>` instead. `AppearingText` still works, but will be removed in
a later version. See [Migrating from LimitLines and AppearingText](/docs/common/components/Text#migrating).

:::

## Dependencies {#dependencies}

```bash npm2yarn
npm install @mui/material @emotion/react @emotion/styled
```

## Usage {#usage}

```tsx
// Before
import { AppearingText } from "@arclockproject/common/components/AppearingText";

<AppearingText speed={30}>Hello there!</AppearingText>;

// After
import { Text } from "@arclockproject/common/components/Text";

<Text speed={30}>Hello there!</Text>;
```

`AppearingText` types at 100ms per character by default. `Text` only types when
`speed` is set, so pass `speed={100}` to keep the old speed.
