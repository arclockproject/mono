## Dependencies {#dependencies}

This component does not require any dependencies.

## Usage {#usage}

```tsx
import Image from "@arclockproject/common/components/Image";
```

- With `enableMovement`, the file can be dragged and zoomed. `defaultTransform` and
  `onTransformChange` work as in [Movable](../Movable/index.mdx#remember-the-position), so you can
  keep the position and zoom when the image remounts.
- With `renderer="auto"`, `.mp4`, `.mov` and `.mkv` files are shown as videos. Anything else is
  shown as an image.
- For videos, `onLoad` runs when the first frame is ready.
- To show `.psd` files, use [PSDViewer](../PSDViewer/index.mdx).

The examples below are live. Edit the code to try your own values. Drag the image to move it.

### Image {#image}

Scroll over the image to zoom.

```tsx live showLineNumbers
<Image
  enableMovement
  onError={() => console.error("Image: Error!")}
  onLoad={() => console.log("Image: Loaded!")}
  renderer="auto"
  src={`${REMOTE.base}/PXQZNGjZIFo.webp`}
  styleImage={{
    width: "100%",
    height: "100%",
  }}
/>
```

### Video {#video}

Videos play muted and on a loop. `controls` shows the video controls, but only while
`enableMovement` is off. Add `enableMovement` to drag the video instead.

```tsx live showLineNumbers
<Image
  autoPlay
  controls
  enableMovement={false}
  renderer="auto"
  src={`${REMOTE.base}/PXQZNGjZIFo.mp4`}
  styleImage={{
    width: "100%",
    height: "100%",
  }}
/>
```
