## Dependencies {#dependencies}

This component does not require any dependencies.

To show `.psd` files, it also needs [PSDViewer](../PSDViewer/index.mdx) and its dependencies.

## Usage {#usage}

```tsx
import Image from "@arclockproject/common/components/Image";
```

The examples below are live. Edit the code to try your own values. Drag the image to move it.

### Image without PSDViewer {#image-without-psdviewer}

Without a PSD renderer, `.psd` files are loaded as normal images.

```tsx live showLineNumbers
<Image
  autoPlay
  controls
  enableMovement
  onError={() => console.error("Image: Error!")}
  onLoad={() => console.log("Image: Loaded!")}
  renderer="auto"
  src={`${REMOTE.base}/PXQZNGjZIFo.webp`}
  styleImage={{
    width: "100%",
    height: "100%",
  }}
/>
```

### Image with PSDViewer {#image-with-psdviewer}

`.psd` files are shown with `PSDViewer`.

```tsx
import Image from "@arclockproject/common/components/Image";
import PSDViewer from "@arclockproject/common/components/PSDViewer";
```

```tsx live showLineNumbers
<Image
  autoPlay
  controls
  enableMovement
  onError={() => console.error("Image: Error!")}
  onLoad={() => console.log("Image: Loaded!")}
  psdRenderer={{
    component: PSDViewer,
    isLazy: false,
  }}
  renderer="auto"
  src={`${REMOTE.base}/PXQZNGjZIFo.webp`}
  styleImage={{
    width: "100%",
    height: "100%",
  }}
/>
```

### Image with lazy PSDViewer {#image-with-lazy-psdviewer}

To keep your bundle small, load `PSDViewer` lazily. It is only downloaded when a `.psd` file is
shown. `Image` wraps it in `<Suspense />` for you, so you don't need to add one.

```tsx
import Image from "@arclockproject/common/components/Image";
import { lazy } from "react";
const PSDViewer = lazy(
  () => import("@arclockproject/common/components/PSDViewer"),
);
```

```tsx live showLineNumbers
<Image
  autoPlay
  controls
  enableMovement
  onError={() => console.error("Image: Error!")}
  onLoad={() => console.log("Image: Loaded!")}
  psdRenderer={{
    component: PSDViewer,
    isLazy: true,
  }}
  renderer="auto"
  src={`${REMOTE.base}/PXQZNGjZIFo.webp`}
  styleImage={{
    width: "100%",
    height: "100%",
  }}
/>
```
