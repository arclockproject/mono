## Dependencies {#dependencies}

```bash npm2yarn
npm install @mui/material @emotion/react @emotion/styled
```

## Usage {#usage}

```tsx
import {
  LimitLines1,
  LimitLines2,
} from "@arclockproject/common/components/Text";
```

MUI `Typography` that cuts text off after 1 or 2 lines.

The examples below are live. Edit the code to try your own values. The text counts from 0 to 150.

### Resizing {#resizing}

Drag the slider to change the width. The cut-off moves with it.

```tsx live
function TextPlayground() {
  const [width, setWidth] = useState(300);
  const text = "The quick brown fox jumps over the lazy dog. ".repeat(6);

  return (
    <div>
      <input type="range" min={80} max={700} value={width} onChange={(e) => setWidth(Number(e.target.value))} /> {width}px
      <div style={{ width, border: "1px dashed var(--ifm-color-emphasis-400)", padding: 8, marginTop: 8 }}>
        <LimitLines1 variant="h6">{text}</LimitLines1>
        <LimitLines2>{text}</LimitLines2>
      </div>
    </div>
  );
}
```
