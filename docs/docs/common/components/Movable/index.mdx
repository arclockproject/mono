## Dependencies {#dependencies}

This component does not require any dependencies.

## Usage {#usage}

```tsx
import Movable from "@arclockproject/common/components/Movable";
```

The examples below are live. Edit the code to try your own values.

### Moving and zooming {#moving-and-zooming}

Drag with the mouse or one finger. Zoom with the mouse wheel or by pinching. Turning a feature
off resets its position or zoom.

```tsx live
function MovablePlayground() {
  const [enableMovement, setEnableMovement] = useState(true);
  const [enableZoom, setEnableZoom] = useState(false);

  return (
    <div>
      <label>
        <input type="checkbox" checked={enableMovement} onChange={() => setEnableMovement(!enableMovement)} /> enableMovement
      </label>{" "}
      <label>
        <input type="checkbox" checked={enableZoom} onChange={() => setEnableZoom(!enableZoom)} /> enableZoom
      </label>
      <Movable
        enableMovement={enableMovement}
        enableZoom={enableZoom}
        style={{
          width: "100%",
          height: "160px",
          background: "rgb(52, 11, 55)", // Purple
        }}
      >
        <div
          style={{
            width: "100%",
            height: "100%",
            background: "rgb(3, 70, 3)", // Green
          }}
        >
          <p style={{ color: "white" }}>
            {enableMovement && enableZoom
              ? "Move and zoom me!"
              : enableMovement
                ? "Move me!"
                : enableZoom
                  ? "Zoom me!"
                  : "You can't move or zoom me!"}
          </p>
        </div>
      </Movable>
    </div>
  );
}
```

### Movable acts like a div {#movable-acts-like-a-div}

It accepts all `<div>` props. Your `onMouseDown` and `onTouchStart` run before the drag logic,
even when dragging is off.

```tsx live
function MovableEvents() {
  const [log, setLog] = useState([]);
  const add = (message) => setLog((list) => [message, ...list].slice(0, 4));

  return (
    <div>
      <Movable
        enableMovement
        style={{
          width: "100%",
          height: "120px",
          background: "rgb(52, 11, 55)", // Purple
        }}
        onClick={() => add("onClick")}
        onMouseDown={() => add("onMouseDown (before move logic)")}
      >
        <div
          style={{
            width: "100%",
            height: "100%",
            background: "rgb(3, 70, 3)", // Green
          }}
        >
          <p style={{ color: "white" }}>Click or drag me!</p>
        </div>
      </Movable>
      {log.map((message, i) => (
        <div key={i}><code>{message}</code></div>
      ))}
    </div>
  );
}
```
