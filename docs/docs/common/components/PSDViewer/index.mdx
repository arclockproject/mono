
## Why PSDViewer? {#why}

- **Opens `.psd` files in the browser,** with no server or converter.
- **Show and hide layers and groups,** and see the image redrawn from them, with every blend mode, opacity and fill, layer masks and clipping masks.
- **Loads nothing until the user asks,** so a page with many PSDs stays light.

## Usage {#usage}

```tsx
import PSDViewer from "@arclockproject/common/components/PSDViewer";
```

The file starts loading when the user clicks **Load PSD**. The image saved in the file is shown
first, next to the layer panel.

- Layer effects, adjustment layers and group masks are not drawn, so files that use them can look
  different from Photoshop. The toolbar can switch back to the saved image, which is always exact.
- PSDViewer fills its parent, so give the parent a size and `position: relative`.
- Of the `<div>` props, only `style` and the mouse, touch and wheel handlers are used.

The example below is live. Edit the code to try your own values.

### Loading a PSD file {#loading-a-psd-file}

The demo file has a group with a clipped layer, screen, multiply and overlay layers with lower
opacity, a layer mask and a hidden layer. Click **Load PSD**, then turn layers on and off and
compare the redraw with the expected render. Showing "Hidden layer" adds a red X in the top right.
