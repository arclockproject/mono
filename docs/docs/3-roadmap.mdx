# Roadmap

Components Planned for migration (and improvements)

- Horizontal/Vertical Data Carousel
- Horizontal/Vertical Data Browser (Caching, Jump To, BookMode, Settings, etc...)
- Audio Mixer (Pan Audios, Adjust Speed, Distort Pitch, Independent Start/End times)

Improvements

- Allow direct video data to be passed to `components/Player`
- Allow audio player to play instantly with option to play partial content `library/Audio`

More might be added depending on the migration work needed and state of projects.
