## Dependencies {#dependencies}

```bash npm2yarn
npm install @mui/material @mui/icons-material @mui/x-tree-view @emotion/react @emotion/styled wanakana
```

Babylon.js and babylon-mmd are installed with the package.

If you use Docusaurus, see [Issues](./issues.mdx) for a config fix.

## Usage {#usage}

The example below is live. Edit the code to try your own values. It downloads a 3D model,
motions and music, so it can take a moment to start.

### Full page player {#full-page-player}

A player with music "Melancholy Night", Miku model performing and a single camera motion.

```tsx
import MMD from "@arclockproject/mmd-player";
// FileBrowser is optional and can be removed.
import FileBrowser from "@arclockproject/common/components/FileBrowser";
```

```tsx live
<MMD
  maxWidth="1280px"
  maxHeight="720px"
  presets={() => [
    {
      title: "メランコリ・ナイト",
      subTitle: "(Miku Cover)",
      thumbnail: `${REMOTE.base}/jkZ53T1Pu7k.webp`,
      // Audio source: https://youtu.be/y__uZETTuL8
      music: `${REMOTE.noname0310}/motion/melancholy_night/melancholy_night.mp3`,
      // Motion source: https://www.nicovideo.jp/watch/sm41164308
      vmdCamera: `${REMOTE.base}/メランコリ・ナイト_カメラ.cam.vmd`,
      entities: [
        {
          // Motion source: https://www.nicovideo.jp/watch/sm41164308
          movement: [`${REMOTE.base}/メランコリ・ナイト.chara.vmd`],
          // Model source: https://www.deviantart.com/sanmuyyb/art/YYB-Hatsune-Miku-10th-DL-702119716
          model: {
            file: "yyb_hatsune_miku_10th_v1.02.pmx",
            folder: `${REMOTE.noname0310}/model/yyb_hatsune_miku_10th_ff/`,
          },
        },
      ],
      // Below properties can be excluded if empty (As in "" or [])
      stageFolder: "",
      stagePMX: "",
      entitiesOffset: [],
      entitiesAngle: [],
      actionMemory: [],
    },
  ]}
  rawMMDDetails={() => ({
    pmd: [],
    pmx: [
      `${REMOTE.noname0310}/model/yyb_hatsune_miku_10th_ff/yyb_hatsune_miku_10th_v1.02.pmx`,
    ],
    vmd: [
      `${REMOTE.base}/メランコリ・ナイト_カメラ.cam.vmd`,
      `${REMOTE.base}/メランコリ・ナイト.chara.vmd`,
    ],
  })}
  // FileBrowser is optional and can be removed.
  getFileBrowser={(data) => <FileBrowser {...data} />}
  basePathMMD=""
  loadAudioMeta={(value) => [
    `${REMOTE.base}/${value}.m4a`,
    `${REMOTE.base}/${value}.webp`,
  ]}
  noDebug={false}
/>
```

:::info[Debug player state]

Each MMD Player has its own state. To read or change it for debugging purposes,
pass a ref from `useRef` to the `mmdRef` prop, then use `ref.current.MMDLoadDetails`
([MMDLoadDetails API reference](/docs/api/mmd-player/component#mmd-load-details)).

:::

### Custom resolutions {#custom-resolutions}

The resolution menus list `defaultResolutions`. To add your own, pass the list with yours added.
`width` and `height` get the player's size on screen in CSS pixels; multiply by
`window.devicePixelRatio` for device pixels.

```tsx
import MMD, { defaultResolutions, type Resolution } from "@arclockproject/mmd-player";

const eightK: Resolution = { label: "8K", width: () => 7680, height: () => 4320, ratio: 16 / 9 };

<MMD resolutions={[...defaultResolutions, eightK]} /* … */ />;
```

The default picks are list indexes (0 in fullscreen, 7 otherwise). If your list is shorter, its
first resolution is used.

### Saving presets {#saving-presets}

With `onSavePreset`, the presets tab shows "Save to current preset" and "Save as new preset". After
the user confirms the id, title and subtitle, it gets a copy of the scene. Save it where you keep
your presets and return `true` to update the player's list.

```tsx
<MMD
  /* … */
  onSavePreset={async (preset, isNew) => {
    const response = await fetch(isNew ? "/presets" : `/presets/${preset.id}`, {
      method: isNew ? "POST" : "PUT",
      body: JSON.stringify(preset),
    });
    return response.ok;
  }}
/>
```

Checking that a new preset's `id` is unique is up to you.

### Controls {#controls}

Press <kbd>H</kbd> in the player, or the **Controls** button in its top bar, to see every keyboard,
mouse and touch control. Playback and camera keys only work after clicking the 3D view.
